# Python Data Structures – Core Data Structures

## 📌 Description

This project focuses on Python built-in data structures and how to manipulate them efficiently.

You will work with:
- Lists
- Tuples
- Sets
- Dictionaries

The goal is to understand how to store, access, transform, and safely manage data in Python.

---

## 🎯 Learning Objectives

By the end of this project, you should be able to:

- Iterate over lists and matrices
- Access and modify list elements safely
- Understand immutable vs mutable structures
- Use tuples to return multiple values
- Perform set operations (union, intersection, difference)
- Work with dictionaries (add, update, retrieve values)
- Handle edge cases (empty inputs, missing keys, duplicates)
