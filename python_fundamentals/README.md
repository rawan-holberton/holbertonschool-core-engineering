# Python - Functions and Modules

## Introduction & Context

As programs grow, repeating logic becomes inefficient and error-prone. Functions allow you to encapsulate behavior into reusable blocks, while modules help organize and reuse code across multiple files.

This project introduces the fundamentals of functions and modules in Python, including how Python executes files and handles imports.

## Key Concepts Covered

- Function definition and return values
- Difference between `print` and `return`
- Execution flow inside and outside functions
- Python file execution model
- Use of `if __name__ == "__main__"`
- Importing functions from other files
- Importing variables from other files
- Code reusability and modular design

## Learning Objectives

By the end of this project, you should be able to:

- Define functions with parameters and return values
- Understand the difference between printing and returning
- Implement logic using conditionals and loops inside functions
- Understand how Python executes scripts
- Explain and use `if __name__ == "__main__"`
- Import functions and variables from other modules
- Write reusable and well-structured Python programs
