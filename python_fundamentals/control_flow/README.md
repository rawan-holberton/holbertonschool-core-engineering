# Python - Control Flow

## Description

This project introduces the basics of control flow in Python using conditional statements and loops.

## Learning Objectives

- Use `if`, `elif`, and `else`.
- Compare values with comparison operators.
- Use logical operators.
- Write `while` loops.
- Write `for` loops with `range()`.
- Produce formatted output using loops.

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.x
- Every file starts with:

```python
#!/usr/bin/env python3
```

- Files must be executable.
- Files must end with a newline.
- Code must follow **pycodestyle 2.7.x**.
- No external libraries.
- No `import` statements.
- No functions (`def`).
