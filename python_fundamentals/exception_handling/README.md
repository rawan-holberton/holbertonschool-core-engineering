# Python Exception Handling

## 📌 Description

This project focuses on handling runtime errors in Python using exception handling mechanisms.

You will learn how to write robust programs that can handle unexpected inputs and failures without crashing.

---

## 🎯 Learning Objectives

By the end of this project, you should be able to:

- Understand common Python exceptions (IndexError, TypeError, ZeroDivisionError, KeyError)
- Use `try` / `except` blocks correctly
- Handle specific exceptions instead of broad ones
- Use `else` and `finally` blocks appropriately
- Raise exceptions explicitly when needed
- Write safe and predictable functions

---

## 🧠 Key Concepts

### try / except
Used to catch and handle errors safely.

### else
Executed only if no exception occurs.

### finally
Always executed, whether an exception occurs or not.
